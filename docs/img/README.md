# Screenshots

Place the application screenshots here and reference them from the
[Screenshots](../README.md#screenshots) section of the README.

Suggested names:

| File | Shows |
|------|-------|
| `vm-list.png` | the main window with the VM table |
| `vm-details.png` | the details panel with live statistics |
| `vm-form.png` | the VM creation form |
| `console.png` | the noVNC console window |

Keep them under ~1600 px wide so the README stays readable.
